---
title: "writePackIcon"
---

```kotlin
open fun writePackIcon(modId: String)
```

An optional method that does not need to be called, but exists to give authors an option to customise their pack. By default, it will get the logoFile of the given mod_id, however you can override this method if you want to specify a different location.

#### Parameters

java

| | |
|---|---|
| modId | The mod_id to grab the logoFile from |
